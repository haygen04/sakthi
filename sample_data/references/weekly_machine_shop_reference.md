# Reference Layout: Weekly Machine Shop MIS Report

This document defines the standard manual layout reference for the **Weekly Machine Shop MIS Report** compiled for Machine Shop Managers and Production Engineers.

---

## 1. Header Block
- **Plant Name:** Sakthi Automotive Group - Precision Machining Division
- **Report Title:** WEEKLY MACHINE SHOP MANAGEMENT INFORMATION SYSTEM (MIS)
- **Period:** ISO Week (e.g., Week 45: 02-Nov-2026 to 08-Nov-2026)
- **Target Operations:** CNC Turning, Twin Spindle VMC, Grinding, Balancing & Final Inspection

---

## 2. Executive KPI Cards
1. **Total Input Machined:** 32,400 pcs
2. **Finished Good Output:** 31,880 pcs (98.40% Pass)
3. **Machine Shop Rejection:** 520 pcs (1.60%)
4. **Scrap vs Rework:** 380 Scrap (73.1%) / 140 Reworked (26.9%)

---

## 3. Section 1: Daily Machining Progress
Columns:
- Date
- Target Pcs
- Completed Pcs
- OK Pcs
- Rejected Pcs
- Rejection %
- Machining Rej % vs Raw Casting Faults caught during machining
- Line Efficiency %

---

## 4. Section 2: Machine / Cell-wise Breakdown
Focus on individual machine lines:
- **CNC Cell 1 (Brake Disc Rotor Line A)** - Doosan CNC 1 to 4
- **CNC Cell 2 (Brake Disc Rotor Line B)** - Doosan CNC 5 to 8
- **VMC Cell (Caliper & Knuckle Line)** - Makino / BFW VMCs
- **Grinding & Dynamic Balancing Line**

Columns: Machine Code, Machine Description, Planned OEE/Output, Actual Machined, Rejected, Rejection %, Major Issue

---

## 5. Section 3: Defect Breakdown (Machining Specific)
1. **Dimensional Out of Tolerance (OD/ID/Thickness)** (DEF-DIM-OOT)
2. **Surface Roughness / Tool Chatter / Tool Marks** (DEF-SURF-CHAT)
3. **Drill / Tap Breakage in Component** (DEF-TOOL-BRK)
4. **Chamfer / Burr / Runout Variation** (DEF-RUNOUT)
5. **Subsurface Casting Porosity exposed during machining** (DEF-SUB-POR)

---

## 6. Section 4: Part-wise Quality Matrix

## 7. Section 5: Tooling & Maintenance Observations
